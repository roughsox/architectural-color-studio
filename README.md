# Architectural Color Studio

A workshop for playing with colour and rooms, and for making social posts: a room photograph and its exact swatch card.

Live: https://architectural-color-studio.vercel.app

Start with [STATE.md](STATE.md). Instructions for assistants: [AGENTS.md](AGENTS.md).

```
npm ci
npm run build    # builds dist/ and checks the data
npm run cards    # renders and measures the trio swatch cards
```
